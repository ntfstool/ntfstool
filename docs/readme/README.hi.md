# NTFSTool (ओपन-सोर्स संस्करण)

macOS के लिए मुफ़्त, ओपन-सोर्स, रीड-राइट NTFS, जो Apple के **FSKit**
और NTFSTool के अपने NTFS इंजन (**libntfstool-driver**) पर बना है।

कोई Windows (NTFS) ड्राइव लगाइए और macOS उसे NTFSTool के FSKit ड्राइवर
मॉड्यूल के ज़रिए लिखने योग्य रूप में माउंट कर देता है — कोई कर्नेल
एक्सटेंशन नहीं, कोई macFUSE नहीं, सुरक्षा सेटिंग्स में कोई कमी नहीं,
कोई एडमिन पासवर्ड नहीं। ऐप स्वयं पूरी तरह सैंडबॉक्स में चलता है।

## स्क्रीनशॉट

इस रिपॉज़िटरी से बने ऐप (`make app`) के असली स्क्रीनशॉट। दिखाई गई ड्राइव बिल्ट-इन डेमो मोड (`make demo`) की नमूना ड्राइव हैं, ताकि आप किसी वास्तविक डिस्क के बिना हर स्क्रीन आज़मा सकें।

### मुख्य विंडो

आपकी सभी NTFS ड्राइव के लिए एक विंडो। हर वॉल्यूम अपनी स्थिति एक नज़र में दिखाता है — **रीड और राइट**, **केवल-पढ़ने योग्य** या **माउंट नहीं** — साथ में क्षमता बार, माउंट पॉइंट, बस (USB / Thunderbolt) और डिवाइस का विवरण, तथा *Finder में दिखाएँ* और *बाहर निकालें*।

### निर्देशित सेटअप: न पासवर्ड, न कर्नेल एक्सटेंशन

NTFSTool एक सामान्य FSKit फ़ाइल सिस्टम मॉड्यूल है। macOS सिर्फ़ एक स्विच माँगता है, जो
**सिस्टम सेटिंग्स → सामान्य → लॉगिन आइटम और एक्सटेंशन → फ़ाइल सिस्टम एक्सटेंशन** में है। ऐप इसे कदम-दर-कदम
समझाता है और बदलाव को अपने आप पहचान लेता है।

![फ़ाइल सिस्टम एक्सटेंशन चालू करें](../screenshots/enable-extension.png)

**केवल-पढ़ने योग्य** माउंट करता है और आपके डेटा को जोखिम में डालने के बजाय ठीक-ठीक बताता है कि इसे कैसे सुधारें।

## यह रिपॉज़िटरी क्या है

यह NTFSTool का **ओपन-सोर्स लर्निंग / रेफ़रेंस संस्करण** है। यह Mac App Store पर उपलब्ध मुफ़्त NTFSTool से बना है और उसी आर्किटेक्चर को बनाए रखता है, लेकिन जानबूझकर छोटा और पठनीय रखा गया है:

- हर सोर्स फ़ाइल में अंग्रेज़ी में टिप्पणियाँ हैं, ताकि आप समझ सकें कि FSKit फ़ाइल सिस्टम मॉड्यूल, NTFS इंजन के ऊपर बना C ब्रिज
  और सैंडबॉक्स वाला SwiftUI/AppKit फ्रंट एंड कैसे एक साथ काम करते हैं;
- ड्राइवर सरल, सीधे I/O पथ का उपयोग करता है (कोई कैशिंग लेयर या प्लेटफ़ॉर्म-विशिष्ट परफ़ॉर्मेंस ट्यूनिंग नहीं);
- ऐप केवल बुनियादी काम करता है (कोई टेलीमेट्री नहीं, कोई डायग्नोस्टिक्स अपलोड नहीं, नेटवर्क एक्सेस बिल्कुल नहीं);
- लाइसेंसिंग, एक्टिवेशन या ट्रायल का कोई कोड नहीं है।

अगर आप सिर्फ़ एक उपयोगकर्ता के रूप में सबसे अच्छा अनुभव चाहते हैं, तो आधिकारिक बिल्ड [ntfstool.com](https://ntfstool.com) से इंस्टॉल करें।
NTFSTool Pro (क्लोज़्ड सोर्स) पुराने macOS संस्करणों के लिए दूसरा ड्राइवर, डिस्क रिपेयर और अन्य टूल जोड़ता है।

## विशेषताएँ

- NTFS वॉल्यूम को पढ़ें **और लिखें**; macOS उन्हें FSKit ड्राइवर मॉड्यूल के ज़रिए अपने आप माउंट करता है
- सैंडबॉक्स वाला ऐप; ड्राइवर यूज़र स्पेस में सैंडबॉक्स वाले FSKit मॉड्यूल के रूप में चलता है
- हर NTFS वॉल्यूम की स्थिति दिखाता है: रीड-राइट, केवल-पढ़ने योग्य (Windows हाइबरनेट / फ़ास्ट स्टार्टअप), Apple के बिल्ट-इन ड्राइवर द्वारा
  केवल-पढ़ने योग्य, माउंट नहीं
- सिस्टम सेटिंग्स में फ़ाइल सिस्टम एक्सटेंशन चालू करने में आपका मार्गदर्शन करता है
- Finder में खोलें, बाहर निकालें, डिस्क की जानकारी
- 20 UI भाषाएँ
- एक्सटेंडेड एट्रिब्यूट NTFS नामित स्ट्रीम के रूप में सहेजे जाते हैं (कोई `._` फ़ाइलें नहीं); वैकल्पिक `windows_names` माउंट विकल्प
  उन फ़ाइल नामों को अस्वीकार करता है जिन्हें Windows उपयोग नहीं कर सकता

## आवश्यकताएँ

- चलाने के लिए macOS 15.6 या उसके बाद का; **लिखने की सुविधा के लिए macOS 26 या उसके बाद का संस्करण चाहिए** (macOS 15 पर सिस्टम भौतिक डिस्क के लिए
  Apple के केवल-पढ़ने वाले NTFS ड्राइवर का ही उपयोग करता रहता है)
- बनाने के लिए: Xcode 16.3 या उसके बाद का (FSKit SDK) कमांड लाइन टूल्स के साथ, Swift 5.9+

## बिल्ड — एक कमांड में

```sh
git clone https://github.com/ntfstool/ntfstool.git
cd ntfstool
make            # → build/NTFSTool.app (ad-hoc signed, native architecture)
```

अन्य टारगेट:

| कमांड | यह क्या करता है |
| --- | --- |
| `make run` | ऐप बनाता है और खोलता है |
| `make demo` | इन-मेमोरी डेमो डिस्क के साथ UI चलाता है — न ड्राइवर चाहिए, न Apple Developer खाता |
| `make test` | यूनिट टेस्ट चलाता है |
| `make app UNIVERSAL=1` | arm64 + x86_64 बनाता है |
| `make scan` | जाँचता है कि ट्री में कोई साइनिंग सामग्री या निजी पहचानकर्ता मौजूद न हो |

ड्राइवर टेस्ट `ntfstool-driver` बाइनरी के `mkntfs` और `ntfsfix` सबकमांड से असली NTFS डिस्क इमेज को फ़ॉर्मैट और जाँचते हैं। अगर दोनों टूल Homebrew के `bin`/`sbin` में
या `NTFSTOOL_NTFS_TOOLS=<dir>` द्वारा दी गई डायरेक्टरी में न मिलें, तो ये टेस्ट छोड़ दिए जाते हैं।

## ड्राइवर चलाना (आपका अपना Apple Developer खाता चाहिए)

FSKit मॉड्यूल प्रतिबंधित एंटाइटलमेंट `com.apple.developer.fskit.fsmodule` का उपयोग करता है। macOS केवल उसी मॉड्यूल को लोड करता है
जिसका हस्ताक्षर ऐसी प्रोविज़निंग प्रोफ़ाइल से समर्थित हो जो यह एंटाइटलमेंट देती हो। ad-hoc बिल्ड पूरा UI दिखाता है, लेकिन
सिस्टम ड्राइवर को लोड नहीं करेगा। यह Apple का प्लेटफ़ॉर्म नियम है जो हर FSKit प्रोजेक्ट पर लागू होता है।

1. अपने Apple Developer खाते में दो App ID बनाएँ, जैसे `com.yourname.ntfs` और `com.yourname.ntfs.fskit`।
   दूसरे पर **FSKit Module** कैपेबिलिटी चालू करें, और वैकल्पिक रूप से दोनों पर एक App Group
   (जैसे `TEAMID.com.yourname.ntfs`) चालू करें ताकि ऐप ड्राइवर का लॉग पढ़ सके।
2. दोनों के लिए डेवलपमेंट (या Developer ID) प्रोविज़निंग प्रोफ़ाइल बनाएँ और डाउनलोड करें।
3. अपनी पहचान के साथ बनाएँ:

   ```sh
   TEAM_ID=ABCDE12345 \
   BUNDLE_ID=com.yourname.ntfs \
   SIGN_IDENTITY="Apple Development: Your Name (XXXXXXXXXX)" \
   APP_PROFILE=~/Downloads/app.provisionprofile \
   FSKIT_PROFILE=~/Downloads/fskit.provisionprofile \
   make app
   ```

4. `build/NTFSTool.app` को `/Applications` में कॉपी करें, उसे एक बार खोलें, फिर ड्राइवर को
   **सिस्टम सेटिंग्स → सामान्य → लॉगिन आइटम और एक्सटेंशन → फ़ाइल सिस्टम एक्सटेंशन** में चालू करें।
5. NTFS ड्राइव को दोबारा लगाएँ। अब `mount` उसे `ntfstooloss` प्रकार के साथ सूचीबद्ध करना चाहिए।

सभी बिल्ड विकल्प [`scripts/build-app.sh`](../../scripts/build-app.sh) के शुरुआती हिस्से में दर्ज हैं।
प्रोविज़निंग प्रोफ़ाइल और साइनिंग कीज़ का इस रिपॉज़िटरी में कभी स्थान नहीं है; `make scan` इनकी जाँच करता है।

## संरचना

| पथ | यह क्या है |
| --- | --- |
| `Sources/NTFSTool` | ऐप का एंट्री पॉइंट (`main.swift`) |
| `Sources/NTFSToolApp` | AppKit शेल, SwiftUI व्यू, ऐप मॉडल, सिस्टम सेवाएँ, 20 स्थानीयकरण |
| `Sources/NTFSToolCore` | AppKit के बिना शुद्ध लॉजिक: डिस्क मॉडल, भाषा सूची, सेटिंग्स स्टोर, स्थानीय इवेंट लॉग |
| `Sources/NTFSToolBridge` | C ब्रिज (`ntfstool_bridge.c`) जो `libntfstool-driver` के ऊपर inode-आधारित ऑपरेशन उपलब्ध कराता है |
| `Sources/NTFSToolDriver` | ड्राइवर का Swift कोर (FSKit पर निर्भरता नहीं, किसी भी macOS पर यूनिट-टेस्ट योग्य) |
| `FSKitModule/NTFSToolFS` | FSKit मॉड्यूल (`NTFSToolFS.appex`) जिसे macOS NTFS वॉल्यूम माउंट करने के लिए लोड करता है |
| `Tests/` | ऐप मॉडल और ड्राइवर के यूनिट टेस्ट (असली NTFS इमेज के साथ) |
| `scripts/` | `build-app.sh`, `build-fskit.sh`, `scan-secrets.sh` |

Finder से डिस्क तक एक राइट कैसे पहुँचता है, यह जानने के लिए [docs/ARCHITECTURE.md](../ARCHITECTURE.md) देखें।

- आप इस सोर्स को अपने लिए बना और उपयोग कर सकते हैं, और इसे "NTFSTool पर आधारित" कह सकते हैं।
- अगर आप किसी संशोधित संस्करण या फ़ोर्क को **वितरित** करते हैं (किसी भी ऐप स्टोर सहित), तो आपको उसे अलग नाम और आइकन देना होगा,
  NTFSTool के लोगो हटाने होंगे, और अपना बंडल आइडेंटिफ़ायर उपयोग करना होगा — वह आधिकारिक NTFSTool रिलीज़ जैसा
  दिखना या होने का दावा करना नहीं चाहिए।
- इस रिपॉज़िटरी के असंशोधित बिल्ड को NTFSTool नाम के तहत केवल पूर्व अनुमति से ही पुनः वितरित किया जा सकता है।

NTFS और Windows Microsoft Corporation के ट्रेडमार्क हैं; macOS और FSKit Apple Inc. के ट्रेडमार्क हैं। यह
प्रोजेक्ट Microsoft या Apple से संबद्ध नहीं है।
